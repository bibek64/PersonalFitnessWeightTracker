# Personal Fitness Weight Tracker

This project is a basic [Next.js](https://nextjs.org/) application that lets you track strength workouts directly in your browser. Data is cached locally so no database is required. You can create custom exercises, log sets, and export your data as JSON for further analysis.

## Development

1. Install dependencies: `npm install`
2. Run the development server: `npm run dev`
3. Open [http://localhost:3000](http://localhost:3000) to view the app
4. Build for production: `npm run build`

The API routes currently contain placeholders for future database integration.
